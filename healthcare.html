RingWatch: Oura Ring Integration

Project: A wearable-enabled remote monitoring pilot for heart failure patients.

Role: Technology Advisor

Our team proposed a cardiology outpatient pilot using the Oura Ring Gen 4, a companion app, and an RPM integration bridge into an EHR dashboard. My technology-focused work centered on evaluating wearable capabilities, technical functionality, EHR/API integration, interoperability, and implementation considerations.

Technology focus: wearable sensing, remote patient monitoring, EHR integration, APIs, interoperability, system workflow, privacy/security, and healthcare technology evaluation.
System workflow: Patient wears and syncs the ring → data moves to the RPM dashboard → nurses review trends and triage alerts → urgent issues can be escalated to a cardiologist → outcomes are documented in the EHR.
